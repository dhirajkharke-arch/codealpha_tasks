## Project Overview

The Stock Portfolio Tracker is a Python application that allows users to manage a simple stock portfolio using predefined stock prices.

The user can view available stocks, add stocks to their portfolio, enter the number of shares, calculate investment values, view the complete portfolio, calculate the total portfolio value, and remove stocks.

## Features

- View available stocks and their prices
- Add stocks to the portfolio
- Enter the quantity of shares
- Calculate investment value
- View portfolio details
- Calculate total portfolio value
- Remove stocks from the portfolio
- Validate stock symbols
- Validate share quantity
- Handle invalid user input
- Simple menu-driven interface
