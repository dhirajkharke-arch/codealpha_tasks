# 🎮 Hangman Game

## 📌 Project Overview

A simple text-based Hangman word guessing game developed using Python for the CodeAlpha Python Developer Internship.

The player must guess a randomly selected word one letter at a time before running out of attempts.

## 🎯 Objective

This project demonstrates practical Python programming concepts including:

- Variables
- Lists
- Sets
- Conditional statements
- Loops
- Functions
- String manipulation
- Random module
- Input validation

## ✨ Features

- 🎲 Random word selection
- 🎯 Three difficulty levels
- 🔒 Hidden word display
- 🔤 Letter-by-letter guessing
- 🛡️ Input validation
- 🔁 Repeated guess detection
- ❤️ Limited attempts
- 🪢 ASCII Hangman visualization
- 🏆 Win condition
- 💀 Game Over condition
- 🏅 Score calculation
- 📊 Game statistics
- 🔄 Play-again option

## 🛠️ Technologies Used

- Python 3
- Python Standard Library
- `random` module

## 🎮 Difficulty Levels

| Level | Attempts |
|---|---:|
| Easy | 8 |
| Medium | 6 |
| Hard | 4 |

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python task1.py
```

The project can also be run using Python IDEs such as Pydroid 3.

## 🎯 How to Play

1. Select a difficulty level.
2. The program randomly selects a word.
3. Guess one letter at a time.
4. Correct letters are revealed.
5. Wrong guesses reduce the number of attempts.
6. Previously guessed letters are not accepted again.
7. Guess the complete word before your attempts run out.

## 📊 Scoring

The score is calculated using:

- Word length
- Selected difficulty
- Remaining attempts
